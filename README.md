# C Programming – Small Projects & Applications

A collection of **18 practical C programming projects** developed to strengthen programming fundamentals and apply C concepts to real-world style applications.

This repository focuses on **small applications, management systems, utility programs, and console-based games**.

---

## 📌 Projects Included

### 1. Advanced Calculator
A menu-driven calculator supporting basic arithmetic operations.

**Concepts:** Functions, `switch`, conditional statements, arithmetic operators

---

### 2. Number Guessing Game
A game where the computer generates a random number and the user tries to guess it.

**Concepts:** Random numbers, loops, `if-else`, counters

---

### 3. Quiz Game
A multiple-choice C programming quiz that calculates the user's score.

**Concepts:** Input/output, conditions, counters, `if-else`

---

### 4. Dice Rolling Game
Simulates rolling two dice and displays their values and total.

**Concepts:** Random numbers, loops, `rand()`, `srand()`, `time()`

---

### 5. Simple Billing System
A basic billing application that allows users to add items and calculate the total bill.

**Concepts:** Loops, conditions, menu-driven programming, arithmetic operations

---

### 6. Expense Tracker
Records expenses and calculates the total amount spent.

**Concepts:** Arrays, functions, pointers, loops

---

### 7. Student Grade Management System
Stores student information and marks, then calculates total marks, percentage, and grade.

**Concepts:** Structures, arrays, loops, conditional statements

---

### 8. Student Record Management System
Manages student records with options to add, display, and search records.

**Concepts:** Structures, arrays, functions, searching

---

### 9. Library Management System
A basic library application for adding, searching, displaying, issuing, and returning books.

**Concepts:** Structures, arrays, strings, functions, searching

---

### 10. Bank Account Management System
Simulates basic banking operations such as account creation, deposits, withdrawals, and balance display.

**Concepts:** Structures, pointers, functions, conditional statements

---

### 11. Contact Management System
Stores contact information and provides options to add, display, and search contacts.

**Concepts:** Structures, strings, arrays, `strcmp()`, functions

---

### 12. Simple Calendar
Displays the calendar for a selected month and year.

**Concepts:** Functions, arrays, loops, leap-year logic, mathematical calculations

---

### 13. Shopping Cart System
Allows users to add items, view the cart, and generate a final bill.

**Concepts:** Structures, arrays, functions, loops, arithmetic operations

---

### 14. Unit Converter
Provides conversions for length, temperature, and weight.

**Concepts:** Functions, `switch`, arithmetic operations, menu-driven programming

---

### 15. Password Generator
Generates a random password using letters, numbers, and special characters.

**Concepts:** Character arrays, random numbers, loops, `rand()`, `srand()`

> **Note:** This is an educational random password generator and is not intended to provide cryptographically secure passwords.

---

### 16. Tic-Tac-Toe Game
A two-player console-based Tic-Tac-Toe game.

**Concepts:** Arrays, functions, loops, game logic, condition checking

---

### 17. Hangman Game
A word-guessing game where the player attempts to identify a hidden word.

**Concepts:** Strings, character arrays, functions, loops, character searching

---

### 18. Snake Game
A console-based Snake game with movement, food, snake growth, score tracking, and collision detection.

**Concepts:** Arrays, functions, random numbers, loops, collision detection, game logic

---
