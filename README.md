# C Programming – Small Projects & Applications

A collection of **18 practical C programming projects** developed to strengthen programming fundamentals and apply C concepts to real-world style applications.

This repository focuses on **small applications, management systems, utility programs, and console-based games**.


## 🧠 Concepts Covered

This repository provides practical experience with:

- C Programming Fundamentals
- Variables and Data Types
- Input and Output
- Operators
- Conditional Statements
- `if-else`
- `switch-case`
- `for` Loop
- `while` Loop
- `do-while` Loop
- Functions
- Arrays
- Strings
- Pointers
- Structures
- Structure Pointers
- Random Number Generation
- Searching
- Menu-Driven Programs
- Problem Solving
- Game Logic
- Collision Detection
